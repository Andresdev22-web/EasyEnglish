# Arquitectura del proyecto

Con el fin de tener un proyecto en el cual tengamos separado el backend y el frontend vamos a tener 2 docker-compose.yml en 2 carpetas distinas.

## Backend

servicio en go con una base de datos sqlite q permita guardar el progreso de los estudiantes en sus examenes y cosas asi

## Frontend

proyecto echo en astro para agilizar el rendimiento con paginas estaticas y la implementacion con react para crear componentes dinamicos q necesitemos en casos especiales
