# Tecnologias

lista de las explicaciones de los nombres utilizados en la documentacion 

docker: servicio que permite ejecutar multiples servicios al mismo tiempo de distitna tecnologias sin sufrir conflicto de verciones o de ejecutar multiples servicios incompatibles en un mismo sistema.

imagenes de docker: el model para crear contenedores de docker 

contenedores de docker: una funcion de docker q permite tener una tecnologia almacenada dentro de una "maquina virtual" listas para ser usadas 


traefik : proxi inverso, que permite gestionar las peticiones de los usuarios al servicodr para dirigirlas a los contenedores de docker mediante archicos mucho mas simples y escalables a largo plaso.

docker compose: servicio q permite administrar los contenedores de docker
